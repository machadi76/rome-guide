ROME GUIDE 2.0 — ΠΡΩΤΟΣ ΠΥΡΗΝΑΣ

Άνοιγμα:
1. Αποσυμπίεσε το ZIP.
2. Άνοιξε τον φάκελο RomeGuide.
3. Άνοιξε το index.html.

Νέα στοιχεία:
- νέα mobile αρχική σελίδα
- dark mode
- καθολική αναζήτηση
- αγαπημένα ανά σελίδα
- κάτω navigation bar
- manifest εφαρμογής
- service worker για offline cache όταν σερβίρεται από ιστοσελίδα/localhost
- διατήρηση όλων των παλιών ημερών και κεφαλαίων

Σημαντικό:
Οι φωτογραφίες εξακολουθούν να φορτώνονται από Wikimedia και χρειάζονται internet.
Η πλήρης συσκευασία εικόνων για 100% offline χρήση είναι επόμενη φάση.
