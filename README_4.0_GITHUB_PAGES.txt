ROME GUIDE 4.0 — GITHUB PAGES PWA

Τι προστέθηκε:
- Νέα μοντέρνα αρχική σελίδα τύπου iPhone.
- Σταθερή κάτω μπάρα πλοήγησης σε όλες τις σελίδες.
- Πραγματικός διαδραστικός χάρτης Leaflet/OpenStreetMap.
- Markers και φίλτρα για αξιοθέατα, φαγητό, ξενοδοχείο, WC και νερό.
- Κλικ σε marker για τοπική σελίδα ή Google Maps.
- PWA manifest και εικονίδια 192/512.
- Service Worker για offline αποθήκευση των σελίδων που ανοίγονται.
- Εγκατάσταση στην αρχική οθόνη iPhone/Android.
- Διατήρηση όλων των 91 κεφαλαίων και του υπάρχοντος περιεχομένου.
