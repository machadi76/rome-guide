Σημείωση για iPhone:

Για πλήρη συμπεριφορά εφαρμογής, τα αρχεία πρέπει να φιλοξενηθούν σε HTTPS
(π.χ. GitHub Pages ή Netlify). Το περιεχόμενο και ο σχηματικός χάρτης παραμένουν
διαθέσιμα χωρίς σύνδεση αφού αποθηκευτούν από τον browser.

Οι φωτογραφίες είναι ακόμη εξωτερικές Wikimedia εικόνες και δεν έχουν
ενσωματωθεί όλες τοπικά σε αυτή τη φάση.
