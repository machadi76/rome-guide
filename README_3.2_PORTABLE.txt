ROME GUIDE 3.2 — PORTABLE OFFLINE

Η έκδοση αυτή διορθώνει το πρόβλημα των links όταν το index.html ανοίγει
απευθείας με file://, χωρίς web server.

Αλλαγές:
- Καταργήθηκαν όλα τα fetch() προς τοπικά JSON.
- Τα δεδομένα ενσωματώθηκαν στο assets/portable-data.js.
- Η αναζήτηση λειτουργεί χωρίς server.
- Το Walking Mode λειτουργεί χωρίς server.
- Ο offline σχηματικός χάρτης λειτουργεί χωρίς server.
- Η βάση POI και τα φίλτρα λειτουργούν χωρίς server.
- Τα αγαπημένα και το dark mode λειτουργούν όπου ο browser επιτρέπει localStorage.
- Δεν απαιτείται Service Worker.
- Ελέγχθηκαν οι πραγματικοί τοπικοί σύνδεσμοι: 1449.
- Σπασμένοι τοπικοί σύνδεσμοι μετά τις διορθώσεις: 0.

Οδηγίες:
1. Αποσυμπίεσε ολόκληρο το ZIP.
2. Μην μετακινήσεις μόνο το index.html έξω από τον φάκελο.
3. Άνοιξε RomeGuide/index.html.
4. Τα Google Maps links απαιτούν σύνδεση internet.

Σε iPhone, ορισμένες εκδόσεις της εφαρμογής Files προβάλλουν HTML με περιορισμούς.
Για την πιο αξιόπιστη χρήση άνοιξε το index.html μέσω Safari από έναν φάκελο/hosting.
Η βασική τοπική πλοήγηση δεν χρησιμοποιεί πλέον fetch ή Service Worker.
